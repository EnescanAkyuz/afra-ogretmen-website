# Merve Afra Can - Kişisel CV Web Sitesi

Modern, profesyonel ve mobil uyumlu kişisel CV web sitesi. İlköğretim matematik öğretmeni Merve Afra Can için tasarlanmış minimalist ve sıcak bir portfolyo.

## 🎨 Tasarım Özellikleri

### Tema
- **Minimalist ve temiz tasarım**
- **Beyaz ağırlıklı arka plan**
- **Pastel mavi, yeşil ve bej tonlarında vurgular**
- **Öğretmenlik kimliğini öne çıkaran sıcak ve güven veren stil**

### Renk Paleti
- **Ana Renk**: #7FB3D3 (Pastel Mavi)

- **Vurgu Rengi**: #E6D3A3 (Bej)
- **Koyu Renk**: #2C3E50
- **Açık Renk**: #FFFFFF

## 🚀 Kullanım

### Yerel Geliştirme
1. Dosyaları bir web sunucusunda açın veya:
2. Python ile basit sunucu:
   ```bash
   python -m http.server 8000
   ```
3. Node.js ile:
   ```bash
   npx serve .
   ```

### Kişiselleştirme

#### Profil Fotoğrafı Ekleme
`index.html` dosyasında hero section'daki placeholder'ı değiştirin:
```html
<div class="hero-image">
    <img src="profil-foto.jpg" alt="Merve Afra Can" class="profile-image">
</div>
```

#### İletişim Bilgilerini Güncelleme
`index.html` dosyasında contact section'daki linkleri güncelleyin:
```html
<a href="tel:+905XXXXXXXXX" class="contact-item">
<a href="mailto:gercekmailadresi@email.com" class="contact-item">
<a href="https://linkedin.com/in/gercekprofil" class="contact-item">
```

#### Renkleri Değiştirme
`styles.css` dosyasındaki `:root` değişkenlerini düzenleyin:
```css
:root {
    --primary-color: #YourColor;
    --secondary-color: #YourColor;
    --accent-color: #YourColor;
}
```
